隱私權政策

JARVIS 會將執行功能所需的資料交由外部平台處理。請勿傳送密碼、API 金鑰、完整身分證件、可識別病人的資料，或沒有權限交給這些平台處理的內容。

2. Google OAuth 與 Google 資料用途

目前整合由維護者在伺服器設定 Google OAuth 連線，並非此網站提供的多使用者登入服務。存取能力受實際核准的權限範圍（scopes）、帳號權限及服務設定限制。

  • Google Drive：檢查指定資料夾與分享權限，上傳使用者傳送的檔案，讀取所需檔案內容或中繼資料；保存及更新提醒、對話背景、偏好、工作狀態與操作紀錄。檔案名稱、連結或摘要也可能依功能記錄於 Notion。
  • 文件理解：執行文件／圖片摘要時，服務會讀取 Drive 中相應檔案，並把內容傳給 Gemini 處理；相關摘要可能出現在 LINE 回覆或被要求存入 Notion。
  • 選用的 Google Calendar：完成設定及授權後，查詢指定行事曆的事件，或依交辦建立事件。目前程式的建立流程不新增與會者或寄送邀請。
  • 選用的語音回覆：將回覆文字傳給 Google Cloud Text-to-Speech，將產生的音訊存入 Drive，並透過有期限的存取連結供 LINE 播放。連結期限不等於 Drive 檔案刪除期限。

Google 資料的用途為上述使用者可見功能。JARVIS 對經 Google API 取得資料的使用與轉移，受 Google API Services User Data Policy（包括適用的 Limited Use 要求）限制。本政策不是 Google 對本服務的合規認證，也不擴張已取得的授權範圍。

4. 儲存、保留與安全

資料可能存在後端本機狀態、Google Drive、Notion、LINE，以及處理請求的平台紀錄中。Drive 內的工作紀錄與長期記憶可在服務重新啟動後繼續存在；Notion 頁面及 Drive 檔案不會因為停止聊天而自動刪除。

目前沒有對所有資料類別採用同一個自動刪除期限。近期對話的使用期限、本機佇列的清理，以及雲端操作紀錄的保存各不相同；「不再用於當次對話」不代表已從所有儲存位置刪除。第三方紀錄、備份與垃圾桶另依該平台規則保留。

程式使用 HTTPS API 與平台授權機制，並在上傳流程檢查目標 Drive 資料夾的公開／網域分享。這不構成對所有資料皆已額外加密、端對端加密、零外流或零風險的承諾。維護者具備管理服務所需的技術存取能力；需要人工排查特定內容時，應先取得你的同意，依法或處理安全事件所必要的情況除外。

5. 撤銷授權、查詢與刪除

  • 停止 Google 存取：前往 Google 帳戶的第三方連線，找到 JARVIS 的相關連線並移除授權。依賴 Google 的功能將無法繼續正常運作。
  • 清除記憶：有啟用相關指令時，可用 @memory 查看 檢視長期記憶，或 @memory 清除長期記憶 清空該記憶清單。此操作不會連帶刪除所有工作紀錄、檔案、Notion 頁面、LINE 聊天或供應商紀錄。
  • 刪除雲端內容：可在自己的 Drive 或 Notion 刪除相應檔案／頁面，並依需要處理垃圾桶。進行服務資料清理前，應先聯絡維護者停用相關排程或寫入，避免影響仍在執行的工作。
  • 提出資料請求：寄信到 bill032420@gmail.com，說明要查詢、更正、匯出或刪除的資料及大致日期。不要寄送密碼或 Token；維護者可能需要適度核對身分，再確認可處理範圍、進度及無法刪除的原因。
  • 撤銷不等於刪除：撤銷 Google 授權、封鎖 LINE Bot 或斷開 Notion 整合，不會自動刪除既有副本。維護者無法代替每個第三方平台承諾立即移除其所有紀錄或備份。
